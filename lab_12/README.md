# Завдання 1
Розробити програму, яка вирішуватиме завдання обробки даних з використанням бібліотек Python, згідно з Вашим варіантом.

#### Розроблення настільного застосунку з графічним інтерфейсом із використанням бібліотеки tkinter. Створити просту програму з кнопками, формами введення та відображенням результатів.


1. Структура програми

Програма повинна мати логічну та зрозумілу структуру, що включає розбиття на функції або модулі для різних етапів обробки даних.
Кожна функція повинна виконувати однозначну задачу, мати чітке призначення та при необхідності повертати результати.
2. Складність та функціональність

Програма повинна вирішувати задачу, що передбачає:

імпорт і підготовку даних (збір, очищення, конвертація формату);
обробку даних із застосуванням обраних бібліотек;
виконання розрахунків, аналізу або візуалізації;
представлення результатів у зручному вигляді.
в програмі повинні бути декілька етапів обробки, які демонструють послідовність алгоритмічних дій.
3. Взаємодія з користувачем

Програма повинна передбачати діалог із користувачем, включаючи:

введення параметрів або вибір варіантів дій;
інформування про хід виконання програми;
вивід результатів у зрозумілому та структурованому вигляді.
4. Обробка виключень

Програма повинна передбачати виключні ситуації, такі як:

відсутність файлу або некоректний формат даних;
введення некоректних значень користувачем;
помилки під час обробки даних або виконання алгоритмів.
Всі виключення повинні оброблятися коректно з повідомленням користувачу про помилку.
5. Збереження результатів

Результати обробки або аналізу повинні бути збережені у зовнішніх файлах, таких як CSV, TXT, PDF або зображення.
Програмний код повинен містити коментарі, що пояснюють логіку та призначення ключових блоків.
